# 📈 주식 첫걸음

주식 초보자를 위한 증권시장 분석 웹사이트입니다. 어려운 용어 없이 시장 흐름과 종목 상태를 한눈에 볼 수 있도록 만들었습니다.

> ⚠️ 현재 모든 시세는 학습용 **예시(모의) 데이터**입니다. 투자 권유가 아닙니다.

## 주요 기능

- **홈**: 주요 지수(코스피·코스닥·S&P 500·나스닥·환율) 요약, 관심 종목, 인기 종목
- **종목 분석**: 가격 차트(이동평균선), 🚦 신호등(추세·과열·변동성·PER), 1년 가격 범위, "만약 그때 샀다면?" 계산기, 핵심 지표
- **용어 사전**: 주식 용어를 쉬운 말과 예시로 설명, 화면 곳곳의 `?` 버튼으로 바로 확인

## 실행 방법

빌드 과정 없는 정적 웹사이트입니다. 아무 정적 서버로 열면 됩니다.

```bash
# Windows PowerShell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

브라우저에서 http://localhost:5173 을 엽니다.

## 구조

```
index.html
css/style.css
js/data.js       # 종목·지수·용어 데이터 (실제 시세 API로 교체 지점)
js/analysis.js   # 이동평균, RSI, 변동성, 신호등 판정
js/chart.js      # 의존성 없는 SVG 차트
js/app.js        # 화면 렌더링, 라우팅, 이벤트
serve.ps1        # 로컬 정적 서버
```
